# Human Skills

Capabilities that GTM humans have that agents can't replicate — yet. This catalog helps recipe authors think clearly about where to put humans in the loop.

---

## The hard-to-replicate list

| Skill | Why agents struggle | Who has it |
|-------|-------------------|------------|
| Trust building | Requires track record and reciprocity over time | AE, CS, Events |
| Reading the room | Real-time nonverbal + tonal signals in live conversation | AE, SDR, Events |
| Positioning judgment | Requires deep market intuition + cultural context | PMM, Demand Gen |
| Editorial taste | Knowing what's *good*, not just what's readable | Content, PMM |
| Stakeholder alignment | Political navigation, listening for what's unsaid | RevOps, PMM |
| System architecture | Trade-off judgment under real constraints | GTM Engineer |
| The personal hook | Genuine specificity — not approximated | SDR, AE |
| Experience design | What will make someone *feel* something | Events |
