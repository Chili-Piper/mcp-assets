# GTM Engineer

The GTM Engineer builds and maintains the technical infrastructure that makes AI-assisted GTM possible — integrations, data pipelines, MCP servers, automation workflows.

## Where GTM Engineers bring joy

- **System architecture.** Designing the data flow so every recipe can work without data-quality fires.
- **Integration judgment.** Knowing which tools talk to each other cleanly and which don't.
- **Debugging.** When the agent says "I didn't find any accounts," knowing whether it's a data problem or a prompt problem.
- **Security.** Making sure the six-layer defense model is actually working.
- **Enablement.** Making it easy for non-technical GTM teammates to run complex recipes.

## What agents can take off their plate

| Drudgery task | How AI helps |
|--------------|-------------|
| Writing integration boilerplate | Agent generates the first-draft connector code; engineer reviews and tests |
| Monitoring data pipelines | Agent surfaces anomalies; engineer investigates and fixes |
| Documentation | Agent drafts setup guides from code; engineer edits for accuracy |
| Query writing | Agent translates business questions into SQL; engineer validates and tunes |
| MCP server scaffolding | Agent generates the server skeleton from an API spec; engineer implements |

## Where humans are irreplaceable

- **Architecture decisions.** Which pattern to use — and why — for a system that will outlast the current sprint.
- **Security judgment.** Knowing which data handling shortcut is fine and which one will cause a breach.
- **Trade-off navigation.** Balancing speed, correctness, maintainability, and cost in a real production system.
- **Organizational context.** Understanding why the data is messy and what the right fix actually is.
